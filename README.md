# Orbspire

A drag-orb match-3 RPG prototype made with Godot 4.7.2.

**Play it in your browser:** open this repository's GitHub Pages site and enter the preview password.

- `index.html`, `index.js`, `index.wasm`, `index.pck`: the web build that GitHub Pages serves.
- `project/`: the Godot project (open `project/project.godot` in Godot 4.7.2).

The password screen is a soft lock for a private preview. It is not real security.
